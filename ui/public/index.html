Safe Load Lab - Technical Reference

Controlled Performance Engineering

Safe Load Lab is a local, self-contained load-testing tool and A/B regression gate for developers and DevOps teams. It runs completely on your machine with zero external cloud dependencies or SaaS accounts.

Key CLI Commands

CommandPurpose
sll run --config <file> --i-own-this-targetExecute controlled staged load test
sll ab --url-a <A> --url-b <B> --i-own-this-targetRun automated A/B differential benchmark with regression gates
sll mock --port 8080Start local hermetic mock HTTP server for zero-flake tests
sll import-curl "<curl>"Convert browser cURL to reproducible test JSON
sll import-postman <file.json>Convert Postman Collection v2/v2.1 to test JSON
sll import-openapi <file.json>Convert OpenAPI/Swagger spec to test JSON
sll spike / soak / stressSpecialized traffic patterns (sudden surge, sustained soak, ramp)
sll compare <file1> <file2>Compare two test reports side-by-side
sll validate / planVerify configuration & resolve plan without sending traffic

Export Options & CI/CD

FlagDescription
--out <file.json>Structured JSON report with percentiles & results
--html <file.html>Standalone self-contained HTML dashboard report
--csv <file.csv>Per-request latency, timestamp, status code export
--markdown <file.md>Markdown summary tables (appends to $GITHUB_STEP_SUMMARY in CI)
--prometheus <file.prom>OpenMetrics / Prometheus exposition text format for Grafana
--badge <file.svg>SVG status badge for repository README
--env-file <.env>Load environment variables for {{VAR}} template replacement
--jitter <ms>Inject random millisecond delay between requests

Hard Safety Limits

  • Maximum Test Duration: 600 seconds (10 minutes)
  • Maximum Concurrency: 100 simultaneous workers
  • Maximum RPS: 200 requests per second
  • Maximum Request Body: 1 MB
  • Mandatory Safety Confirmation: --i-own-this-target flag
