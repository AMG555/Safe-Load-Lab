# Release Notes v2.3.0 - Script Exporters, Dynamic Generators, Scenarios & SLA Regression Gating

Safe Load Lab v2.3.0 brings the tool to full parity with enterprise load-testing engines, introducing bi-directional script exporters (**k6** & **Postman**), **dynamic data generators**, **multi-step user journeys with response correlation**, **bandwidth telemetry**, **Unicode latency sparklines**, and **automated SLA regression gating**.

---

## What's New in v2.3.0

### 1. 📤 Bi-Directional Script Exporters (`sll export-k6` & `sll export-postman`)

Export any Safe Load Lab configuration into target script ecosystems:

```bash
# Export to modern k6 JS test script
sll export-k6 load-test.json -o k6-script.js

# Export to Postman Collection v2.1
sll export-postman load-test.json -o postman-collection.json
```

- Also accessible via interactive modal directly inside Web UI Studio (`Export to k6` / `Export to Postman`).
- Maps stages, concurrent users, thresholds, headers, status checks, and query parameters faithfully.

---

### 2. 🎲 Built-In Dynamic Data Generators

Generate dynamic test payloads without requiring external CSV data files:

- `{{$uuid}}` / `{{$guid}}` — Cryptographically secure UUID v4
- `{{$timestamp}}` — Current epoch millisecond timestamp
- `{{$isoDate}}` — ISO-8601 UTC timestamp (`YYYY-MM-DDTHH:mm:ss.sssZ`)
- `{{$randomEmail}}` — Randomized test email address
- `{{$randomInt:min:max}}` — Random integer bounded by min and max
- `{{$randomAlpha:length}}` — Alphanumeric random string
- `{{$randomIp}}` — Synthesized IPv4 address

Usable across request URLs, custom headers, and request bodies. Interactive quick chips toolbar included in Web UI Studio.

### 3. 🗺️ Multi-Step User Journey Scenarios

Model sequential user flows with variable extraction and step dependencies:

```json
{
  "scenarios": [
    {
      "name": "login-and-order",
      "weight": 2,
      "steps": [
        {
          "name": "authenticate",
          "method": "POST",
          "url": "http://127.0.0.1:8080/auth",
          "extract": { "token": "body.token" }
        },
        {
          "name": "create-order",
          "method": "POST",
          "url": "http://127.0.0.1:8080/items",
          "headers": { "Authorization": "Bearer {{token}}" },
          "body": { "sku": "ITEM-{{$randomInt:100:999}}" }
        }
      ]
    }
  ]
}
```

### 5. 🔍 Automated SLA Regression Gate (`sll diff` / `sll check-regression`)

Gate pull requests and CI pipelines with automated performance regression checks:

```bash
# Compare baseline vs current test report
sll diff reports/baseline.json reports/current.json --max-latency-diff 10 --max-error-diff 0
```

- Returns exit code 1 if p95 latency degradation or error rate increases exceed configured thresholds.
- Automatically writes GitHub Actions formatted Step Summary markdown table to `$GITHUB_STEP_SUMMARY`.

---

### 6. 🌐 Network Bandwidth & Throughput Telemetry

- Measures exact request and response byte transmission (`bytesSent`, `bytesReceived`).
- Calculates live throughput in KB/s and MB/s.
- Exposed in OpenMetrics Prometheus scraping endpoint (`safeloadlab_last_test_bytes_total`, `safeloadlab_last_test_throughput_kbps`).
- Displayed on live KPI cards in Web UI Studio.

### 7. 🔓 High-Capacity Limit Unlock (`--unlock-limits` / `--high-capacity`)

For stress-testing on dedicated authorized enterprise hardware:
- Unlocks test durations up to 86,400s (24 hours).
- Unlocks concurrency up to 2,000 workers.
- Unlocks rate limits up to 10,000 requests per second.
